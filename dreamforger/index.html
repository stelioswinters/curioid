KNIGHTMARE OS / SYSTEM GUIDE

DREAMFORGER / BUILD 0.19.0

Dreamforger is the creative workshop running on KNIGHTMARE OS. It turns a starting thought into a structured concept, then carries it into a project-centred studio. The Project Map connects ideas, questions, experiments, decisions and outputs through typed relationships. Professional briefs, estimates, validation plans, decisions and case-study drafts now save inside the active project, alongside its experience, plan, notes and history.

Set an audience, desired outcome and hard constraint. Explore a practical route, a bold route and a wildcard. Compare their heuristic signals, then develop the strongest direction in the Studio with a live mockup, production board, notes and version history.

The Career Suite adds a client brief architect, scope and quote calculator, assumption validation lab, weighted decision matrix and portfolio case-study builder. These tools help structure real work, but they do not replace professional accounting, legal review or direct user research.

The desktop supports multiple first-party app windows with focus, minimize, maximize, close, drag and resize controls. Files indexes your local Studio projects and archived creations; desktop shortcuts, recent-project resume, compact spacing and a session notification centre are available. Settings now includes interface scaling, higher contrast, reduced motion, local storage estimates and backup/recovery entry points. The top-bar project selector switches the active Studio context only after pending changes are safely flushed; recent projects appear first. These are local app records, not access to your computer’s folders. Use Ctrl/Cmd+Alt+M to minimize the active window and Ctrl/Cmd+Alt+Enter to toggle maximize. These are browser UI windows, not separate operating-system processes. Open Start with Ctrl+Shift+Space or Cmd+Shift+Space; press Ctrl+K or Cmd+K from any view to search commands, switch workspaces or find an element in the active Project Map. The Universal OS Hub uses CURIOID’s actual catalogue IDs and project deep links. Its native adapter targets CURIOID Kernel, Connect v1, App SDK v1 and typed artifacts. The project is mounted as a trusted same-origin first-party iframe, not a sandbox boundary. Standalone mode never starts a duplicate message bus. Full project handoff requires the host runtime and an explicit Exchange permission grant.
